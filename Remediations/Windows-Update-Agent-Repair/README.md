# Windows Update Agent Health Remediation

Ensures that endpoints do not fall behind on critical security updates due to disabled or hung update agent services.

### Key Details
* **Article Reference**: [Troubleshooting WUfB on adminsignal.com](https://adminsignal.com)
* **Detection Script**: `Detect-WUAgentHealth.ps1`
* **Remediation Script**: `Remediate-WUAgentHealth.ps1`
* **Run in 64-bit PowerShell**: **Yes**
* **Run as Account**: **System (No)**
